# 선택적인 외부 준비용 플러그인 입력

승인된 자체 개발 `.hpi`/`.jpi`를 외부 준비 도구에 넣을 때 사용하는 폴더입니다. 순수 이미지 빌드/기동에는 필요하지 않습니다.
파일명 대신 manifest의 `Short-Name`으로 식별합니다. 동일 ID의 파일 두 개는 허용하지 않습니다.
서버에서 직접 설치할 곳은 Compose 옆 **`plugins/`**입니다. 서버를 내린 뒤 HPI/JPI와 모든 필수 의존성을 그곳에 놓고 다시 올리면 됩니다. 이미지 재빌드는 하지 않습니다.
바이너리는 Git에서 제외합니다. 릴리스 아티팩트 저장소에 원본과 SHA-256을 보관하십시오.

전체 플러그인 집합의 Core/의존성 및 업무 정책을 확인한 뒤 반입하십시오. 이 폴더의 파일은 이미지 빌드나 서버 시작 시 자동 설치되지 않습니다.
